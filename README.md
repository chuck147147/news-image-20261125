An original illustrated newspaper front page for Wednesday 25 November 2026. A navy, red and cream layout covers twelve world stories, led by the Riyadh tower strike. All artwork is drawn with inline SVG and CSS in `news.html`.

Run with Node 22:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies the rendered image without changing its bytes. No network or external packages are required by the entry program.
